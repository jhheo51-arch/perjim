# 한 달의 이유: 실제 사용자 메시지 검증

검증일: 2026-10-08  
표본: 익명 참여자 5명(P01~P05), 동일한 모바일 화면에서 응답  
목적: 대표 문장의 이해 방식과 다음에 필요한 정보 확인

## 비교한 문장

- A: `배달비가 18% 늘었어요.`
- B: `배달비가 늘어난 건 야근한 화요일 때문이에요.`

## 확인한 관찰

| 항목 | 결과 |
|---|---:|
| 문장 A 선택 | 4명 |
| 문장 B 선택 | 1명 |
| 평균 이해도 | 4.6 / 5 |
| 평균 토스다움 | 4.2 / 5 |
| 평균 행동 의향 | 4.2 / 5 |
| 세부 구성·근거 요청 | 5명 |

선택 이유에서는 숫자가 바로 보여 빠르게 이해된다는 반응이 반복됐다. 다섯 참여자 모두 18%가 어떤 구성으로 만들어졌는지, 배달비의 세부 내용이나 원인을 더 알고 싶다고 적었다.

## 가능한 해석

이 작은 표본에서는 원인을 바로 제시하는 문장보다 숫자를 먼저 제시하는 문장이 더 빠르게 이해됐다. 다만 숫자만 제시하면 충분하지 않았고, 바로 이어지는 세부 구성과 이유가 필요할 가능성이 보였다.

이는 5명의 응답에서 나온 해석이며, 전체 토스 사용자나 고객 비율을 대표하지 않는다.

## 다음 제공물과 다음 시험

2차 문장: `배달비 18% 증가, 야근한 화요일 4번이 원인이에요.`

이 문장은 숫자와 이유를 한 문장에 연결한 다음 시험안이다. 실제 우수성은 아직 확인하지 않았으며, 다음 검증에서는 A와 2차안을 다시 비교한다.

채널별 제작물에는 다음 순서를 적용한다.

1. 숫자: `배달비 18% 증가`
2. 세부 구성: 화요일 4회, 금액·횟수·비교 기준
3. 행동: 화요일 저녁 알림 또는 내 배달비 구성 보기

## 자료 처리

이 문서는 익명 집계와 반복 반응만 기록한다. 참여자의 원문 응답, 개인 식별 정보, 기기 정보는 공개 저장소에 올리지 않는다.
