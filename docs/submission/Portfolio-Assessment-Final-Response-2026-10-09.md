## 공고와 연결되는 증거

| 공고의 업무와 역량 | 제출 증거 | 아직 하지 않은 일 |
|---|---|---|
| 경제, 문화와 생활 트렌드의 브랜드 적용 | 공개 자료를 가계부 콘텐츠 〈한 달의 이유〉로 바꾼 사례 연구 | 공개 신호가 전체 고객 욕구를 뜻하는지 확인하지 않음 |
| Meta, Google 등 매체별 소재 기획 | 카드 6장, Meta 게시글, 뉴스레터 2편, 영상 구성안 | 광고 집행과 영상 촬영 없음 |
| 결과를 다음 콘텐츠에 반영 | 문장 응답 2회와 완성 카드 응답 5건을 읽고 세 번째 카드 수정 | 수정 카드 재확인과 실제 게시 성과 없음 |
| 외부 플랫폼 발굴과 제휴 | 어피티, 오늘의집과 캐릿 비교, 어피티 공동 연재 제안서 | 실제 연락, 협상과 계약 없음 |
| 주도성과 빠른 학습 | 조사, 기획, 제작, 검증 화면, 응답 분석과 웹 수정까지 직접 수행 | 조직 안에서의 협업 경험으로 해석할 수 없음 |

## 이번에 추가된 증거

완성 카드 첫 3장에 익명 응답 5건을 받았습니다. 계산 근거와 가상 사례는 5명 모두 구분했습니다. 그러나 자동 분석 기능처럼 느꼈다는 응답이 4건, 잘 모르겠다는 응답이 1건이었고 목표한 브랜드 역할을 고른 응답은 없었습니다.

“그날은 왜 주문했을까요?”라는 질문형 제목을 “그날의 이유는 직접 적었습니다”로 바꾸고, 결제 내역 분석 결과가 아니라 가상 인물의 자기 기록임을 본문에 표시했습니다. 이 결과는 문구 수정의 근거이며 광고 성과나 전체 고객 의견이 아닙니다.

## 제출 판단

현재 제출본은 트렌드 발견, 브랜드 해석, 콘텐츠 제작, 실제 반응 확인과 다음 제작물 수정이 한 사례 안에서 이어집니다. 공고의 모든 업무 경험을 증명하지는 않지만, 지원자가 어떤 기준으로 만들고 고쳤는지는 확인할 수 있습니다.

제출 순서는 PDF, 웹 포트폴리오, 필요할 때 엑셀 순서를 권합니다. 엑셀은 면접에서 응답 원자료와 과장하지 않은 해석 범위를 확인할 때 보조 자료로 사용합니다.
