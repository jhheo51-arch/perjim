# 퍼짐 기획서

작성일: 2026년 10월 8일

## 서비스 목적

개인 창작자와 소규모 브랜드가 SNS 주소를 입력하면 공개 콘텐츠를 확인하고, 보완할 요소와 다음 콘텐츠 방향을 추천받는 서비스다. 상세 통계를 먼저 준비할 필요 없이 시작할 수 있다.

## 해결하려는 문제

일반적인 바이럴 조언은 내 콘텐츠와 어떤 관계가 있는지 판단하기 어렵다. 유행하는 소재를 발견해도 자신의 주제에 연결할 방법이 필요하다. 퍼짐은 읽은 소개와 글을 근거로 제안하고, 확인하지 못한 내용은 결과에서 구분한다.

## 기본 사용 흐름

1. SNS 홈 주소를 입력한다. 주소는 최대 5개까지 등록한다.
2. 서버가 접근 가능한 공개 소개나 RSS 글을 읽는다. RSS는 사이트가 공개하는 최근 글 목록이다.
3. 계정 이름, 소개, 글, 본문, 날짜의 확인 여부를 보여준다.
4. 공개 자료에서 찾은 검토점과 다음 콘텐츠 초안을 제안한다.
5. 현재 관심 키워드와 연결할 소재를 검토한다.
6. 필요할 때만 상세 통계를 추가해 반응 변화를 비교한다.

한 줄 소개는 선택 입력이다. 공개 정보에서 주제를 찾지 못했을 때 추천 기준으로 사용할 수 있다.

## 주요 기능

| 기능 | 동작 | 결과의 범위 |
|---|---|---|
| 공개 콘텐츠 분석 | SNS 주소를 확인하고 소개 또는 공개 피드를 읽는다 | 로그인 제한과 지원 범위에 따라 일부 항목을 읽지 못할 수 있다 |
| 자료 확인 표시 | 읽은 항목과 확인하지 못함을 나란히 보여준다 | 빈값을 0이나 추정 수치로 바꾸지 않는다 |
| 보완할 요소 | 소개, 제목, 읽은 글과 게시 날짜에서 점검할 내용을 제안한다 | 공개 글이 없으면 콘텐츠가 부족하다고 판정하지 않는다 |
| 다음 콘텐츠 추천 | 읽은 제목에서 후속 소재를 고르거나 선택 소개로 초안을 제안한다 | 공유 효과를 예측하거나 보장하지 않는다 |
| 관심 키워드 | 오늘과 이번 주 검색 관심을 보여주고 관련 뉴스는 펼쳐 확인한다 | 검색량과 SNS 반응을 구분한다 |
| 콘텐츠 구성 | 메시지, 첫 장면, 질문과 다음 편의 약속을 검토한다 | 초안 작성과 실제 게시를 구분한다 |
| 상세 통계 | 같은 조건의 최근 3개와 이전 3개 게시물 반응률을 비교한다 | 선택 기능이며 실제 수치를 직접 등록한다 |
| 판단 기록 | 선택한 시험안과 당시 통계를 브라우저에 보관한다 | 새 통계를 추가하면 이전 선택과 변화를 검토한다 |

## 정보 수집과 지원 범위

Instagram, 네이버 블로그, 티스토리, 브런치와 주요 SNS 홈 주소를 등록할 수 있다. 주소 등록과 콘텐츠 열람 가능 여부는 별개다. 네이버 블로그와 티스토리는 공개 RSS를 통해 제목, 날짜와 본문 일부를 읽는다. 나머지 지원 사이트는 접근 가능한 페이지의 공개 소개를 읽는다. 임의의 외부 사이트는 자동으로 열람하지 않는다.

Instagram의 이미지와 영상 내용, 조회, 좋아요, 공유, 저장과 팔로우는 현재 자동 분석하지 않는다. 로그인 화면이나 페이지 안내를 실제 소개로 사용하지 않는다. 읽지 못한 항목에는 **확인하지 못함**을 표시한다.

Google Trends의 한국 공개 피드를 읽는다. 오늘 키워드와 수집한 이번 주 기록을 구분한다. 지난 날짜의 자료를 소급 생성하지 않는다. 블랙키위와 트렌드어워드는 확인 시점이 있는 공개 참고 자료다. 네이버 데이터랩, 빅카인즈와 썸트렌드는 원문 링크와 사용자가 등록한 수치 비교를 제공하며 인증이 필요한 자료는 자동 연결하지 않는다.

## 추천 기준

현재 추천은 공개 자료와 입력 주제에 정해진 규칙을 적용하는 방식이다. 외부 생성 모델을 호출하지 않는다. 제목과 본문 일부의 표현에서 찾은 주제는 후보로 표시한다. 공개 글이 없으면 시작용 제안임을 밝힌다.

현재 관심과 내 소재의 연결은 검색 키워드의 단어 관련성으로 찾는다. 무관한 유행을 억지로 연결하지 않는다. 뉴스 원문과 검색 자료의 확인 시점을 보여준다.

## 선택 통계의 계산

같은 계정, 플랫폼, 유료 광고 여부, 게시 후 관측 시점과 도달 또는 조회 기준이 같은 자료끼리 비교한다. 형식을 따로 선택할 수 있다. 반응률은 해당 반응이 확인된 게시물의 반응 수 합계를 같은 게시물의 기준 수 합계로 나눈다.

공유, 저장과 게시물 기여 팔로우를 각각 비교한다. 미확인 수치는 제외하고 자료 수를 표시한다. 3%에서 4%로 변하면 차이는 1%p다. 전체 사람의 비율이나 고유 사용자 수를 뜻하지 않는다. 3개 비교는 운영 기준이며 원인이나 통계적 확신을 입증하지 않는다.

## 저장과 실행

서비스는 Node.js 22 이상에서 실행한다. Node.js는 이 서비스를 컴퓨터에서 실행하는 프로그램이다. 별도 패키지 설치나 인증값 없이 `npm start`로 시작할 수 있다. 기본 주소는 http://127.0.0.1:4191/ 이다. 같은 컴퓨터에서 접근하는 로컬 서비스이며 GitHub 저장소를 만들었다고 외부 웹사이트로 배포되는 것은 아니다.

직접 등록한 통계와 선택 기록은 해당 브라우저에 저장된다. 기록 파일을 내려받을 수 있고, 가져오기는 콘텐츠 기록을 병합한다. 가져온 파일의 선택 이력은 자동 병합하지 않는다. 서버가 보관한 키워드 수집 기록과 개인 입력 기록은 제출 저장소에 포함하지 않는다.

## 검증과 남은 일

자동 검사 20개에서 주소 처리, 공개 피드 해석, 확인하지 못함 표시, 추천 범위, 통계 비교와 빈값 처리를 확인했다. 실제 Instagram 주소를 입력해 공개 이름은 확인하고 소개, 게시물, 이미지와 반응은 확인하지 못함으로 표시되는 결과를 확인했다.

실제 이용자의 공유 증가, 브랜드 기억과 재방문 성과는 아직 측정하지 않았다. 향후에는 이용자가 추천한 안을 선택한 비율, 콘텐츠 제작까지 걸린 시간과 재사용 여부를 측정한다. 실제 게시물 반응을 확보한 경우에만 변화와 추천의 관계를 추가 검토한다.
