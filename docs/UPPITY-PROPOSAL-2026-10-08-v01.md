# 어피티 × 토스 제휴 제안 검토: 한 달의 이유

2026-10-08 · 지원자 독립 제안 · 미협의·미집행. 아래 역할·일정·산출물은 제안 조건이며 어느 회사의 동의나 제공을 뜻하지 않습니다.

## 이미 있는 것에서 출발하기

어피티는 소비를 기록한 뒤 그 값어치를 돌아보는 방법을 이미 설명합니다. 공식 제휴 페이지는 뉴스레터·영상 광고와 브랜드 협업 사례를 안내하며 토스 관련 행사 사례도 소개합니다. 따라서 소비 회고의 발명이나 두 회사의 최초 협업을 주장할 근거는 없습니다.

- [값어치 다이어리 설명이 포함된 머니레터, 2022-05-19](https://uppity.co.kr/💰가격-올리기-vs-양-줄이기/): 지출 기록 뒤 값어치를 돌아보는 기존 방법 확인.
- [어피티 공식 제휴 안내](https://uppity.co.kr/partnership/): 뉴스레터·영상 상품 및 협업 사례 확인. 매체 규모나 성과 수치는 이번 제안의 예상 도달로 환산하지 않음.

## 검토한 세 방안

| 방안 | 추가되는 가치 | 약점 | 판단 |
|---|---|---|---|
| 기존 소비 회고에 토스 로고·링크 추가 | 제작 부담이 낮음 | 독자 경험이 거의 같고 토스의 역할이 송출비 지원에 머묾 | 우선하지 않음 |
| 토스 거래 데이터와 어피티 회고 연동 | 기록 부담을 낮출 가능성 | 실제 기능·접근 권한·동의·개발 일정 미확인. 포트폴리오에서 실행 가능한 것처럼 약속할 수 없음 | 별도 검토 과제 |
| 읽기 → 한 건 돌아보기 → 7일 뒤 선택을 다시 보기 | 편집 콘텐츠에 직접 해보는 과정과 후속 이야기를 연결 | 참여 이탈과 브랜드 기억 부족 가능성. 소규모 확인이 필요 | 이번 제안 |

선택 이유는 새로운 기록 도구를 만드는 것보다, 기존 회고 콘텐츠를 읽은 독자가 시작하고 다시 돌아올 이유를 구체화할 수 있기 때문입니다. 이 구조의 효과나 독창성은 아직 검증하지 않았습니다.

## 한 문장 제안

**어피티가 소비를 돌아볼 질문을 편집하고, 토스가 그 질문을 쉽게 해볼 수 있는 콘텐츠 경험과 제작·확산을 지원하는 ‘한 달의 이유’ 2회 연재를 제안합니다.**

| 대상 | 기존 콘텐츠에 더하는 것 | 왜 필요한가 | 확인할 것 |
|---|---|---|---|
| 독자 | 완독 뒤 바로 해볼 한 건 회고 카드, 7일 뒤 재확인 질문 | 자신의 사정에 적용하는 시작점을 제공 | 질문을 혼자 이해하는지, 평가받는 느낌은 없는지 |
| 어피티 | 후속 원고의 질문·자발적 응답 소재, 재사용 조건을 합의한 카드·참여지 | 기존 편집 자산을 반복 참여로 확장할 기회 | 실제 후속 참여, 제작 부담, 기존 값어치 다이어리와의 구분 |
| 토스 | 복잡한 돈 이야기를 쉽게 이해하도록 돕는 브랜드 경험 | 기능 이용 권유 전에 브랜드의 태도를 전달 | 브랜드를 무엇으로 기억하는지, 설명이 쉽고 신뢰할 만했는지 |

다른 후원사도 지원할 수 있는 구조입니다. 토스를 제안하는 이유는 ‘돈을 쉽게 이해하도록 돕는다’는 캠페인 메시지와의 적합성입니다. 독점 데이터나 토스만 가능한 기술이 차별점이라는 주장은 하지 않습니다. 제작 지원만 기억된다면 협업 목적을 달성하지 못한 것으로 봅니다.

## 구체적인 제공물과 독자 경험

1. **첫 원고:** 야근과 배달비를 소재로 한 가상 이야기, 회고 질문, 직접 해볼 한 가지를 함께 읽음. 초안은 [콘텐츠 페이지](../campaign.html#letter)에 제작.
2. **6장 카드뉴스:** 관심 → 가상 사례 → 사실·이유 구분 → 판단 → 자기 회고 → 브랜드 메시지. [PNG 묶음](../assets/campaign-2026-10-08/one-month-reason-cards.zip) 제작 완료.
3. **독자 참여:** 금액을 공개하지 않고 자기 메모장에 ‘지출 한 건 / 당시 상황 / 그때 필요했던 것 / 다음에 유지하거나 바꿀 것’을 기록. 특정 금융 앱·가입·거래 데이터 연결 불필요.
4. **7일 뒤 후속 원고:** 선택을 실행했는지보다 선택이 여전히 맞는지 돌아보는 질문. 후속 원고도 [콘텐츠 페이지](../campaign.html#followup)에 제작. 예약 발송 기능은 구현·실행하지 않음.
5. **선택적 독자 이야기:** 제휴가 성사된 뒤 별도 동의와 편집 검수를 거친 응답만 활용. 현재 포트폴리오는 독자 자료를 수집하지 않음.

## 제안하는 역할·협의 조건

| 항목 | 제안 |
|---|---|
| 어피티 | 독자 맥락 검토, 원고 공동 편집, 광고 표기·발송 일정 확인, 기존 콘텐츠와 중복 검토 |
| 토스 | 브랜드 메시지 검토, 디자인·참여 경험 제작 지원, 제작·매체 비용 협의, 합의한 채널에서 확산 |
| 공동 | 오해 소지가 있는 소비 이유 표현 수정, 공개 응답 활용 범위 합의, 결과를 보고 후속 소재 결정 |
| 파일 전달 | 1080×1350 PNG 6장, 게시글 문안, 첫 원고·후속 원고, 원본 HTML/CSS |
| 제안 일정 | 착수 후 1주차 편집·검수 → 2주차 1회차 발행 → 7일 후 후속편 → 응답 검토. 실제 확정 일정 아님 |
| 견적 | 원고·디자인 제작비, 뉴스레터 송출비, 선택적 확산비를 분리해 문의. 금액과 최소 집행 조건 미확인 |
| 수정·권리 | 초안 1회·수정 2회를 협의 시작안으로 제시. 원고·디자인 소유, 유료 광고 재사용, 기간·채널을 계약 전 합의 |
| 진행 조건 | 제작 책임·광고 표기·비용·자료 이용 범위 합의 후에만 실제 게시 검토 |

## 결과를 보는 기준

- **브랜드:** 노출 뒤 자유롭게 떠오른 브랜드와 이유, 메시지 이해, ‘돈을 쉽게 이해하도록 돕는다’는 인식. 노출 전후 비교를 해도 소규모 표본으로 효과를 일반화하지 않음.
- **참여:** 원고 유입→회고 안내 도달→후속편 재방문. 클릭·저장을 브랜드 신뢰와 동일시하지 않음. 실제 매체에서 제공 가능한 항목·분모·기간은 협의.
- **수정 판단:** 실제 고객 사례나 자동 분석으로 오해하면 표현부터 수정. 내용은 기억하지만 브랜드와 이유가 연결되지 않으면 토스 역할 설명 수정. 소수 응답 결과를 수익·신뢰 상승률로 표시하지 않음.

현재 완료된 것은 독립 제안 분석과 콘텐츠 제작입니다. 어피티 검수·연락·견적·계약·발행·독자 검증은 수행하지 않았습니다.
