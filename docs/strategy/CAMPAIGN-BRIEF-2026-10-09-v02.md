# 〈한 달의 이유〉 캠페인 제작 기준 v02

2026-10-09 · 토스 Brand Marketing Specialist 지원용 독립 프로젝트 · 실제 의뢰·승인·집행 없음

## 목표와 지원자 역할

목표는 ‘토스는 돈을 쉽게 이해하도록 돕는다’는 인식을 콘텐츠로 제안하고, 독자가 한 건의 소비를 스스로 설명할 수 있게 만드는 것이다. 이는 측정된 기존 인식이나 토스 내부 목표가 아니다.

지원자는 공개 신호 조사, 브랜드 가설, 캠페인 메시지, 카드·원고, 매체별 구성, 파트너 후보 비교와 제안, 소규모 문장 응답 분석, 웹 포트폴리오 구현을 직접 수행했다. 토스의 직원이나 외부 파트너와 공동 제작한 결과물이 아니다.

## 소재와 표현의 경계

- 2026년 10월 6·13·20·27일의 배달 주문 4건을 각 18,000원으로 **가상 설정**해 합계 72,000원을 계산했다. 실제 고객 자료나 평균 생활비가 아니다.
- 전월 거래 자료가 없어 ‘18% 증가’는 최종 제작물에 사용하지 않는다. 1·2차 검증 문장에 남아 있는 18%는 당시 시험 문구다.
- 야근은 가상 인물이 자기 생활을 돌아본 이야기다. 거래 내역이 야근을 추론하거나 원인을 증명한 것이 아니다.
- 계좌 연동, 자동 분석, 알림 설정 등 실제 토스 기능을 약속하지 않는다. 참여자는 자기 메모장에 지출 한 건을 적을 수 있다.

## 반응을 반영한 구조

1차 익명 문장 응답 5건에서는 숫자 중심 A가 4건 선택됐고, 세부 근거를 더 알고 싶다는 의견이 있었다. 2차 익명 5건에서는 생활 맥락을 한 문장에 붙인 B가 더 이해하기 쉽다는 선택 3건을 받았지만 계속 볼 의향은 A 평균 4.8/5, B 3.2/5였다. B를 실제 기능으로 오해한 응답도 3건, 불확실 1건 있었다. [집계와 한계](../validation/SECOND-MESSAGE-RESULT-2026-10-09-v01.md)를 따로 기록했다.

따라서 **짧은 숫자 → 계산 내역 → 인물의 말 → 독자의 선택 → 자기 회고 → 브랜드 메시지**로 6장을 편집했다. 이는 편집 판단이며 새 카드가 더 효과적이라는 검증 결과는 아니다.
