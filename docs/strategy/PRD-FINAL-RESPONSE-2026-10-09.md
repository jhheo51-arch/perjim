# Trend to Trust 기획서

## 1. 만들려는 것

공개 경제 자료와 콘텐츠 반응에서 생활비 부담이라는 신호를 찾고, 이를 토스가 돈을 이해하도록 돕는 브랜드로 기억되게 하는 콘텐츠로 바꿉니다. 대표 결과물은 가계부 캠페인 **〈한 달의 이유〉**입니다.

이 프로젝트는 토스의 의뢰나 승인을 받은 일이 아닙니다. 실제 고객 정보, 토스 내부 자료, 광고 성과를 사용하지 않은 개인 제안입니다.

## 2. 보여주려는 업무 방식

`트렌드 발견 → 브랜드가 맡을 역할 결정 → 콘텐츠 제작 → 반응 확인 → 다음 제작물 수정`

1. 공개 자료에서 생활비 부담과 소비 이유에 관한 신호를 확인합니다.
2. 토스의 역할을 지출을 평가하는 사람이 아니라 돈의 맥락을 이해하도록 돕는 브랜드로 정합니다.
3. Meta 카드뉴스, 게시글, 뉴스레터와 채널별 제작안을 만듭니다.
4. 익명 참여자에게 문장과 완성 카드의 이해 여부를 확인합니다.
5. 반복된 오해를 다음 카드의 제목과 본문에 반영합니다.

## 4. 검증과 수정

| 확인 | 표본 | 관찰 | 반영 |
| --- | ---: | --- | --- |
| 첫 문장 비교 | 익명 5건 | 숫자로 시작한 문장을 4명이 선택 | 첫 장에서 계산 가능한 금액을 먼저 제시 |
| 두 번째 문장 비교 | 익명 5건 | 생활 맥락 문장은 이해를 도왔으나 기능 오해가 나타남 | 근거 없는 증가율을 빼고 계산과 인물의 말을 분리 |
| 완성 카드 반응 | 익명 5건 | 계산과 가상 사례는 모두 구분했으나 4명이 자동 분석 기능으로 이해 | 세 번째 카드에 인물이 직접 적은 이야기라고 명시 |

완성 카드 반응에서 계산 이해와 가상 사례 구분은 각각 5건 모두 확인됐습니다. 브랜드 역할 선택은 0건이었고, 명확성 평균은 4.8점, 계속 볼 의향 평균은 3.0점이었습니다. 표본이 작고 지인 중심일 수 있어 전체 고객 반응이나 캠페인 성과로 일반화하지 않습니다.

## 5. 데이터와 저장 기준

- 검증 화면은 이름, 연락처, 계정 정보를 받지 않습니다.
- 응답은 참여자의 기기에 먼저 저장하고 결과 파일로 내려받습니다.
- 원자료, 요약, 수정 판단을 제출용 엑셀에서 구분합니다.
- 가상 인물과 거래 내역은 실제 고객 자료처럼 표현하지 않습니다.

## 6. 완료 기준과 남은 일

현재 단계의 완료 기준은 공개 자료에서 출발한 판단, 채널별 제작물, 세 차례 반응 확인, 응답에 따른 카드 수정이 한 흐름으로 연결되는 것입니다. 이 흐름은 구현했습니다.

실제 게시 뒤의 도달, 저장, 클릭과 브랜드 인식 변화는 확인하지 못했습니다. 다음에는 수정 카드의 재확인과 실제 게시 결과 기록이 필요합니다.

## 7. 다음 구현 단계

브랜드 이름, 목표 고객, 브랜드가 전할 약속, 공개 자료와 후보 채널을 입력하면 캠페인 기획서와 채널별 초안을 만드는 범용 모델로 확장할 계획입니다. 오늘의집에는 주거와 생활 신호를 집 안의 선택 이야기로, 무신사에는 패션과 세대 문화의 신호를 스타일 선택 이야기로 바꾸는 방식입니다. 현재 자동 생성 기능은 구현되어 있지 않습니다.
