# 완성 카드 반응 확인 설계

## 확인할 질문

완성 카드 첫 3장을 별도 설명 없이 읽었을 때 다음 내용을 확인합니다.

1. 72,000원이 18,000원짜리 배달 4건의 합계라고 이해했는가
2. 인물과 거래 내역을 가상 사례로 구분했는가
3. 토스가 거래 내역으로 야근 이유를 자동 분석한 기능으로 오해하지 않았는가
4. 토스를 돈을 쉽게 이해하도록 돕는 브랜드로 받아들였는가
5. 카드의 이해도와 나머지 카드를 계속 볼 의향은 어떠한가

## 진행 방법

- 새로운 참여자 5명에게 같은 화면을 보여줍니다.
- 먼저 카드 3장을 읽게 하고 추가 설명은 하지 않습니다.
- 참여자 번호만 P01부터 P05까지 기록합니다. 이름과 연락처는 받지 않습니다.
- 한 기기의 같은 브라우저에서 한 명씩 입력합니다.
- 5건이 모이면 JSON 파일을 내려받아 자유 응답과 오해 사례를 함께 읽습니다.

## 수정 결정

응답 수가 작으므로 통과율이나 고객 비율로 일반화하지 않습니다. 계산 근거를 잘못 이해한 응답, 가상 사례를 실제 데이터로 본 응답, 자동 분석 기능으로 오해한 응답을 먼저 확인합니다. 반복되는 문제가 있으면 해당 카드 한 장을 수정하고 변경 이유를 기록합니다. 문제가 없더라도 캠페인 효과가 검증됐다고 표현하지 않습니다.
