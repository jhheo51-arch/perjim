# Trend to Trust 제출 전 점검 v03

## 적합도 판단

**직무에 맞는 프로젝트다.** 특히 공개 신호를 토스 브랜드 역할로 해석한 과정, 매체별 카피·제작안, 외부 파트너 비교, 실제 소규모 반응을 다음 카드에 반영한 과정은 공고의 업무와 직접 연결된다. 다만 **개인 제안 프로젝트**이므로 실제 광고 집행·성과 분석, 파트너와의 협의, 내부 디자이너·영상 PD와의 협업, 온·오프라인 이벤트 운영 경험을 대신 증명하지는 못한다.

| 공고 요소 | 제출 증거 | 정확한 수행 범위 |
| --- | --- | --- |
| 트렌드 접목 | 공개 통계·플랫폼·문화 신호 → 가계부 소재 → 브랜드 메시지 | 자료 조사와 캠페인 가설. 고객 수요 검증 아님 |
| 매체별 소재 | [카드 6장·원고](../campaign-v03.html), [채널별 콘티](../campaign-kit-v02.html) | 카드·문안 제작. 영상·광고 집행 전 |
| 결과 반영 | 1·2차 익명 문장 비교 각 5건, 첫 3장 수정 | 실제 문장 반응. 카드 자체의 효과 미검증 |
| 외부 플랫폼·제휴 | 실제 후보 세 곳 비교, [어피티 제안](../partner-proposal-v02.html) | 공개 자료 기반 제안. 접촉·계약 없음 |

| 협업 커뮤니케이션 | 역할·제작물·검수·권리·비용 조건을 나눈 전달안 | 실무 협업 이력은 없음 |
| 주도성과 학습 | 퍼짐 보조 도구, 두 차례 문장 검증, 카드 v01→v03 | 개인 수행·프로토타입. 토스 내부 경험 아님 |

## 제출할 묶음

1. [웹 포트폴리오](../index.html): 전체 흐름과 역할을 빠르게 파악.
2. [지원용 PDF 3쪽](Trend-to-Trust-Brand-Marketing-2026-10-09-v01.pdf): 역할·실제 증거·한계 요약.
3. [완성 카드 6장·원고 v03](../campaign-v03.html): 콘텐츠 감각과 수정 결과.
4. [채널별 제작안](../campaign-kit-v02.html)과 [어피티 제휴안](../partner-proposal-v02.html): 공고의 매체·파트너 업무에 대응.
5. [2차 검증 기록](SECOND-MESSAGE-RESULT-2026-10-09-v01.md): 판단의 원자료 범위와 한계.

이전 [카드 v01](../campaign.html), [첫 3장 v02](../campaign-v02.html), [제출 점검 v02](SUBMISSION-AUDIT-2026-10-09-v02.md)는 변경 이력을 확인하는 보관본이다. 제출 링크의 대표 콘텐츠로 사용하지 않는다. 기존 `퍼짐-프로젝트소개.pdf`와 통계 기록 엑셀은 보조 도구의 기술 자료이며 캠페인 대표 제출물보다 뒤에 둔다.

## 아직 비어 있는 증거

- 완성 카드의 독자 이해와 실제 기능 오해 여부. 문장 시험과 다르다.
- 광고 송출·브랜드 지표의 실제 결과, 파트너 접촉·협업, 온·오프라인 행사 운영.
- 지원자의 공개 이름·연락 경로·이력서 링크. 사용자가 제공하기 전에는 임의로 쓰지 않는다.

공고가 프로젝트별 역할과 기여도를 정확히 표시하라고 요구하므로, 웹·PDF 모두 개인이 직접 한 일과 제안에 그친 일을 구분했다. 최종 제출 직전에는 지원자 식별 정보와 링크의 접근 상태를 확인해야 한다.
