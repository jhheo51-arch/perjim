# 한 달의 이유 · 브랜드 캠페인 제작 기준

2026-10-08 · 토스 지원용 독립 캠페인. 실제 의뢰·브랜드 승인·광고 집행 없음.

## 목적과 소재

브랜드 목표는 **‘토스는 내 돈을 쉽게 이해하도록 돕는다’는 인식**을 형성할 수 있는지 확인하는 것이다. 현재 사람들이 토스를 다르게 인식한다는 조사 결과는 없다. 가계부는 그 태도를 생활 속 지출로 보여주는 콘텐츠 소재다. 토스의 실제 가계부 기능 구현 여부나 신규 기능 출시를 전제로 하지 않는다.

주요 독자는 돈을 돌아보고 싶지만 숫자만으로는 자기 상황을 설명하기 어려운 20–34세라는 가설을 둔다. 모든 독자에게 해당한다고 주장하지 않는다. 절약 팁보다 맥락 이해가 필요한지부터 실제 사람에게 확인해야 한다.

| 층위 | 이번 결정 |
|---|---|
| 브랜드 목적 | 돈을 쉽게 이해하도록 돕는 브랜드라는 인식 |
| 캠페인 | 한 달의 이유 |
| 표현 소재 | 지출 한 건과 그날의 생활 장면 |
| 독자 행동 | 지출 이유를 한 줄로 직접 돌아보기 |
| 제품 연결 | 선택적 후속 검토. 실제 기능·알림 설정·개인 거래 연동은 이번 콘텐츠에 포함하지 않음 |

## 완성한 제작물

- [카드뉴스 PNG 6장 묶음](../assets/campaign-2026-10-08/one-month-reason-cards.zip): 각 1080×1350. HTML 원본의 실제 렌더 결과.
- [어피티 제안 분석](UPPITY-PROPOSAL-2026-10-08-v01.md): 기존 회고 콘텐츠에 추가되는 가치, 역할·제작·검수·권리 조건.

영상은 구성 제안 단계다. 카드뉴스·원고 제작 완료를 모든 매체 소재 제작 완료로 표현하지 않는다. 게시·집행·효과 검증과도 구분한다.

## 예시 자료의 생성 규칙

첫 에피소드는 지원자가 만든 가상 인물과 상황이다. 배달 주문 4건을 각 18,000원으로 설정해 72,000원을 계산했다. 세부 내역은 10월 6·13·20·27일 각 1건이다. 비교 월과 실측 자료가 없으므로 증가율·이전 달 대비 변화는 제시하지 않는다. 이 날짜·금액·야근 설정은 실제 고객 자료가 아니다.

금액은 지출을 나타낼 뿐 이유를 입증하지 않는다. 야근은 가상 인물이 직접 회고하는 이야기 설정으로만 제시한다. 데이터로 야근을 자동 추론한 결과나 원인 검증으로 설명하지 않는다. 2·3번째 에피소드 아이디어와 기존 가상 VOC 12건도 실제 반응이 아니다.

## 메시지·형식 기준

- 핵심 문장: ‘쓴 돈을 보기 전에, 그날의 나부터.’
- 감정: 돈을 잘못 썼다는 평가보다 이해하고 선택할 여지를 제공.
- 구조: 생활 장면으로 시작 → 숫자와 이유를 구분 → 본인이 선택 → 자기 회고 질문 → 브랜드 메시지.
- 금액·수치는 가상 표기와 함께 사용. 가상 인물의 말은 ‘설정’으로 명시.
- 카드 마지막 문장은 캠페인용 제안 카피이며 토스 공식 슬로건으로 표시하지 않음.

## 검증 계획

먼저 목표 독자 5명에게 제작물을 보여준다. 노출 전후 질문이 답을 유도하지 않도록 첫 질문은 ‘무슨 내용으로 이해했나요?’로 한다. 그 다음 기억나는 브랜드·이유, 불편한 표현, 실제 사례/기능으로 오해한 부분을 확인한다. 비교안을 쓸 때는 읽는 순서를 번갈아 배정한다.

이 단계는 문제를 찾는 탐색이며 성과 측정이 아니다. 이해 문제·브랜드 연결·불편한 표현의 원문을 기록하고 실제 관찰 뒤 수정한다. 결과 칸은 현재 비어 있다. 공감·클릭·저장·반복 참여와 브랜드 신뢰를 별도 관찰하며 클릭 증가를 신뢰 상승으로 표현하지 않는다.

## 퍼짐의 비중

대표 제출물은 캠페인과 콘텐츠다. 퍼짐은 공개 자료의 읽기 범위·선택 이유를 남기는 보조 도구로 후반부에 연결한다. 27개 자동 검사는 기술 동작의 근거로만 둔다. 이 캠페인의 공식 자료를 퍼짐이 모두 자동 수집했다거나, 이 도구의 결과로 메시지 효과가 검증됐다고 표현하지 않는다.
