## 대표 사례: 생활비 리셋

공개 통계와 플랫폼 자료에서 생활비 부담, 정보 탐색, 깊이 있는 콘텐츠에 대한 신호를 확인하고 “돈을 줄이기 전에, 흐름부터 봅니다”라는 캠페인 메시지로 번역했다.

확인한 자료의 사실, 지원자의 해석, 포트폴리오용 실행안을 다음처럼 구분한다.

| 구분 | 내용 | 상태 |
|---|---|---|
| 공개 사실 | 가계지출·소비성향 통계, YouTube 정보 이용·콘텐츠 트렌드 | 원문 링크로 확인 |
| 해석 | 절약보다 소비 이유를 이해하려는 욕구가 있을 수 있음 | 캠페인 가설 |
| 실행안 | 생활비 리셋 캠페인, 매체 소재, 크리에이터 제휴 | 미집행 시뮬레이션 |
| VOC | 공감·근거 요청·행동 요청 12건 | 화면 작동용 가상 자료 |
| 다음 검증 | 목표 이용자 5명 메시지 이해 확인 | 제출 전 수행 필요 |

## 업무 도구: 퍼짐

퍼짐은 공개 콘텐츠와 검색 관심 신호를 읽고, 확인한 정보와 확인하지 못한 정보를 구분하며, 다음 콘텐츠 두 안과 선택 이유를 남기는 도구다. 캠페인 성과를 자동 예측하거나 브랜드 전략을 대신 결정하지 않는다.

일반 추천은 기준 글, 두 콘텐츠 안과 제작 전 확인 사항을 함께 보여준다. 반복되는 안내 표현이 있으면 조건을 정리하는 안을, 그 밖에는 경험과 관점을 잇는 안을 우선 검토한다. 이는 제목과 공개 본문 일부에 적용하는 규칙이며 실제 반응 효과를 뜻하지 않는다.

## 보조 사례: 토스 머니북

`case.html`은 토스 머니북의 공식 공개 자료를 읽고 메시지, 온라인·오프라인 채널 역할과 후속 콘텐츠 두 안을 정리한 독립 분석이다. 대표 캠페인의 실제 집행 근거가 아니라, 퍼짐의 브랜드 분석 기준을 보여주는 보조 사례다.

- [사례 근거와 제안](toss-case.json)
- [2024년 출간 발표](https://toss.im/tossfeed/article/moneybook)
- [공식 에디션](https://toss.im/tossfeed/edition/the-money-book)
- [2024년 제작 회고](https://toss.im/tossfeed/article/outsight-themoneybook)

제품 안에서 검증된 토스의 결과를 SNS 성공 공식으로 사용하지 않는다. 다른 시기와 단위의 수치를 합치거나, 조회를 브랜드 신뢰로 바꾸어 표현하지 않는다.
