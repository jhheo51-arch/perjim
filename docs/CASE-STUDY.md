## 대표 사례: 가계부 콘텐츠 ‘한 달의 이유’

공개 통계와 플랫폼 자료에서 생활비 부담, 정보 탐색, 깊이 있는 콘텐츠에 대한 신호를 확인하고 “돈을 줄이기 전에, 흐름부터 봅니다”라는 캠페인 메시지로 번역했다.

확인한 자료의 사실, 지원자의 해석, 포트폴리오용 실행안을 다음처럼 구분한다.

| 구분 | 내용 | 상태 |
|---|---|---|
| 공개 사실 | 가계지출·소비성향 통계, YouTube 정보 이용·콘텐츠 트렌드 | 원문 링크로 확인 |
| 해석 | 절약보다 소비 이유를 이해하려는 욕구가 있을 수 있음 | 캠페인 가설 |
| 실행안 | ‘한 달의 이유’ 가계부 시리즈, 매체 소재, 파트너 제안 | 미집행 시뮬레이션 |
| 실제 메시지 검증 | 익명 참여자 5명의 A/B 선택·정성 의견 | 소규모 실제 검증, 전체 고객 대표 아님 |
| 제작 완료 | 카드 6장, 첫·후속 뉴스레터 원고 | 브랜드 승인·게시 전 |
| 2차 메시지 검증 | 문장별 이해·계속 볼 의향·기능 오해를 익명 5건으로 확인 | 새 카드의 효과는 아직 미확인 |

## 보조 도구: 퍼짐

퍼짐은 공개 콘텐츠와 검색 관심 신호를 읽고, 확인한 정보와 확인하지 못한 정보를 구분하며, 다음 콘텐츠 두 안과 선택 이유를 남기는 도구다. 캠페인 성과를 자동 예측하거나 브랜드 전략을 대신 결정하지 않는다.

일반 추천은 기준 글, 두 콘텐츠 안과 제작 전 확인 사항을 함께 보여준다. 반복되는 안내 표현이 있으면 조건을 정리하는 안을, 그 밖에는 경험과 관점을 잇는 안을 우선 검토한다. 이는 제목과 공개 본문 일부에 적용하는 규칙이며 실제 반응 효과를 뜻하지 않는다.

`case.html`은 토스 머니북의 공식 공개 자료를 읽고 메시지, 온라인·오프라인 채널 역할과 후속 콘텐츠 두 안을 정리한 독립 분석이다. 대표 캠페인의 실제 집행 근거가 아니라, 퍼짐의 브랜드 분석 기준을 보여주는 보조 사례다.

## 실제 메시지 검증

2026년 10월 8일, 익명 참여자 5명이 숫자 중심 A안과 이유 중심 B안을 비교했다. A안은 4명에게 선택됐고, 모두 증가 수치의 세부 구성이나 원인을 더 알고 싶다고 답했다. 이를 바탕으로 숫자 → 세부 근거 → 다음 행동 구조의 2차 문장을 만들었다.

이어진 2차 비교의 익명 응답 5건에서는 생활 맥락을 붙인 B가 이해하기 쉬운 문장으로 3명에게 선택됐지만, 계속 볼 의향 평균은 A 4.8점, B 3.2점이었다. B를 실제 토스 자동 분석 기능으로 오해한 응답이 3건, 불확실하다는 응답이 1건 있었다. 따라서 B를 최종 표지로 쓰지 않고, 계산 가능한 가상 숫자 4건·72,000원 → 날짜별 내역 → 인물의 자기 설명으로 [첫 3장](../campaign-v02.html)을 수정했다. 비교 월 자료가 없는 18% 증가 표현은 제작물에서 제외했다. 수정 카드 자체는 아직 독자 검증 전이다.
