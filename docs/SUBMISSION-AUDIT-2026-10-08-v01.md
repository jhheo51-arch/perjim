# Trend to Trust 제출 전 점검

점검일: 2026년 10월 8일  
대상: 토스 Brand Marketing Specialist 포트폴리오

## 현재 판단

브랜드 목표·완성 콘텐츠·제휴 제안이 연결된 상태다. 이를 실무 집행 경험의 충족으로 판단하지 않는다. 다만 **실제 사람의 반응**과 **지원자 식별 정보**가 빠져 있어 그대로 제출하면 완성된 시뮬레이션으로만 읽힐 위험이 있다.

제작 완료: [카드·원고](../campaign.html), [어피티 제휴안](UPPITY-PROPOSAL-2026-10-08-v01.md), [브랜드 목적과 검증 계획](CAMPAIGN-BRIEF-2026-10-08-v01.md). 실제 독자 검증·게시·제휴는 별도다.

## 공개 상태

- [웹 포트폴리오](https://jhheo51-arch.github.io/trend-to-trust/)와 [퍼짐 화면](https://jhheo51-arch.github.io/trend-to-trust/tool.html)은 공개되어 있다.
- 퍼짐의 공개 주소는 화면 확인용이다. 공개 자료 수집은 [README 실행 안내](../README.md#실행하기)에 따라 로컬 서버를 실행해야 한다.
- [파트너 후보 비교](PARTNER-SHORTLIST-2026-10-08-v01.md)는 공개 자료를 바탕으로 작성되어 있다. 실제 접촉과 협업은 수행하지 않았다.
- 공개 주소 준비와 실제 사용자 검증은 별개다. 아래의 미완료 항목은 계속 보완해야 한다.

## 직무 기준 점검

| 직무 요구 | 현재 증거 | 판단 |
|---|---|---|
| 외부 채널·플랫폼 발굴 및 제휴 | 후보 비교와 어피티 협업 가치·역할·조건 | 발굴·제안 근거 있음, 실제 제휴 수행은 미확인 |
| Meta·Google 소재 기획 | 카드 6장·게시글 제작, 영상 구성 제안 | 카드 제작 확인, 영상·광고 집행 미수행 |
| 결과 분석과 다음 콘텐츠 반영 | 가상 VOC 분류와 1차→2차 수정 | 부분 충족: 실제 반응 표본 필요 |
| 온드 채널 콘텐츠 | 전체 웹 콘텐츠와 첫·후속 뉴스레터 원고 | 제작 확인, 실제 채널 게재 전 |
| 소셜 미디어 이해 | 채널별 역할·상태와 카드 문안 | 기획 근거 있음, 실제 반응은 미확인 |
| 트렌드 접목 | 사실→해석→브랜드 역할 | 충족 |
| 협업 커뮤니케이션 | 제휴안과 역할·한계 표기 | 부분 충족: 협업 산출물과 조율 기록 없음 |
| 주도성과 빠른 학습 | 도구 제작, 27개 검사, 3일 수정 과정 | 강점 |

## 제출 전에 반드시 보완할 2가지

### 1. 실제 사용자 5명 검증

가상 VOC는 구조 설명에는 유효하지만 결과 증거가 아니다. 1차·2차 소재를 같은 조건으로 보여주고 이해한 메시지, 선택 이유, 근거 필요 지점, 다음 행동을 익명으로 기록한다. 실제 반응을 확보하면 가상 VOC와 섞지 않고 별도 구역에 표시한다.

### 2. 제출자 정보

첫 화면과 README에 이름, 지원 직무, 이메일 또는 지원용 연락 경로, 이력서 링크를 넣는다. 공개 주소는 이미 준비되어 있다. 지원자가 공개할 이름·연락 경로·이력서 주소를 정한 뒤 추가하고, 제출 직전에 링크와 모바일 화면을 다시 확인한다.

## 있으면 강해지는 보완

- Meta 릴스 1개와 YouTube 15초 영상의 실제 스토리보드 또는 모션 시안
- 제휴 제안 메일 초안, 역할 분담표, 일정과 검수 기준
- 캠페인 목표→매체 지표→브랜드 지표가 이어지는 측정표
- 면접에서 3분 안에 설명할 수 있는 발표용 요약

## 제출에서 제외하거나 주의할 것

- 가상 VOC 빈도를 고객 전체의 비율로 표현하지 않는다.
- 퍼짐이 Instagram 게시물 이미지나 비공개 반응을 자동 분석한다고 쓰지 않는다.
- `토스 머니북` 보조 사례와 `한 달의 이유` 대표 캠페인을 같은 실제 프로젝트처럼 합치지 않는다.
- 자동 검사 통과를 마케팅 성과 검증으로 표현하지 않는다.

## 권장 제출 묶음

1. 첫 링크: Trend to Trust 웹 포트폴리오
2. 제작 근거: 카드 6장과 뉴스레터 원고, 어피티 제휴안
3. 보조 자료: 통합 PRD와 실제 사용자 검증 1장
4. 보조 자료: 퍼짐 화면과 기술 검증, 영상 구성 제안

현재 상태의 가장 큰 강점은 **브랜드 목적을 완성 콘텐츠와 구체적인 제휴안으로 연결했다는 점**이다. 가장 큰 약점은 **실제 사용자 반응과 지원자 정보가 아직 없다는 점**이다.
