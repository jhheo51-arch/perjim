# 〈한 달의 이유〉 2차 메시지 검증 결과

기록일: 2026년 10월 9일 · 응답 5건 · 익명·소규모 비교

## 질문과 관찰

같은 화면에서 A `배달비가 18% 늘었어요.`와 B `18% 늘어난 배달비, 야근한 화요일 4번을 함께 돌아봐요.`를 비교했다. 각 문장의 이해도와 계속 보고 싶은 정도는 1~5점으로 받았다. 이 결과는 **문장 시험**이지 완성 카드뉴스나 캠페인의 효과 측정이 아니다.

| 항목 | 관찰 |
| --- | --- |
| 더 이해하기 쉬운 문장 | A 2명, B 3명 |
| 평균 이해도 | A 4.4점, B 5.0점 |
| 평균 계속 볼 의향 | A 4.8점, B 3.2점 |
| 실제 토스의 자동 거래 분석 기능으로 B를 오해했는가 | 예 3명, 모르겠음 1명, 아니요 1명 |
| 개인별 계속 볼 의향 비교 | A가 더 높은 응답 4건, B가 더 높은 응답 1건 |

자유 응답은 1건만 기록됐다. 그 응답은 숫자로 한눈에 보이고 세부사항도 알려주는 점을 선택 이유로 적었고, `18% 비교 기준이 궁금해`라고 추가 정보를 요청했다. 이를 5명의 공통 의견으로 일반화하지 않는다.

## 해석과 다음 결정

B는 이해하기 쉽다는 선택을 한 명 더 받았지만, 계속 볼 의향은 낮았고 기능 오해가 있었다. 따라서 B를 승리 문장이나 캠페인 표지로 채택하지 않는다. A의 수치 중심 도입은 살리되, 바로 다음 장에서 계산 근거를 보여주고 생활 이유는 **가상 인물이 스스로 설명한 것**으로 분리한다.

시험 문구의 `18% 증가`는 비교할 이전 달 내역이 없어 실제 제작물에서 입증할 수 없다. 최종 시안에는 사용하지 않는다. 대신 설정된 가상 내역 4건 × 18,000원 = 72,000원을 표지에 제시하고, 다음 장에 날짜별 내역을 공개한다. 수정된 첫 3장은 [카드 시안 v02](../campaign-v02.html)에서 볼 수 있다. 이전 [카드 6장 v01](../campaign.html)은 수정 전 제작물로 보존한다.

제출용 [완성 카드 6장 v03](../campaign-v03.html)은 이 첫 3장과 후반 3장, 첫·후속 뉴스레터 원고를 한 편으로 묶었다. v02는 편집 중간 단계를 확인하는 기록이다.

## 한계와 다음 확인

- 표본 5건은 목표 고객 전체를 대표하지 않는다. 1차와 2차 참여자가 동일한지도 확인하지 못했다. 두 차례 질문도 달라 전후 효과를 인과적으로 비교할 수 없다.
- 문장 점수와 선택은 실제 게시 반응이나 브랜드 인식 변화를 뜻하지 않는다.
- 다음에는 수정된 카드 3장을 맥락 설명 없이 보여주고, 무엇을 이해했는지, 왜 72,000원인지, 토스의 실제 기능으로 여겼는지, 다음 장을 볼지 자유롭게 설명받는다. 결과가 나오기 전까지 v02의 효과를 주장하지 않는다.

원본 응답은 참여자 브라우저에만 저장된다. 저장소에는 개인별 원자료를 올리지 않고 이 집계와 판단만 기록한다.
