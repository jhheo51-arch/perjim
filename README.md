# 퍼짐

공개 콘텐츠를 읽고, 보완할 요소와 다음 콘텐츠의 구성안을 제안하는 도구입니다.

[소개 PDF](docs/퍼짐-프로젝트소개.pdf) · [기획서](docs/PRD.md) · [검증 Excel](docs/퍼짐-기능검증과통계기록.xlsx)

분석 대상은 공개 피드(RSS)를 제공하는 블로그의 제목과 본문 일부입니다. Instagram 개별 게시물과 이미지, 비공개 통계는 자동으로 읽지 않습니다.

## 핵심 설계

**주소 입력 → 자료 확인 → 콘텐츠 두 안 비교 → 선택적으로 반응 기록**

- 읽은 글과 추천 근거를 연결하고, 확인하지 못한 정보는 구분해 표시합니다.
- 오늘과 이번 주 키워드에서 소재와 뉴스 근거를 확인합니다.
- 직접 입력한 게시물 반응을 계산하고, 토스 머니북 사례에서 자료와 제안의 연결을 보여줍니다.

## 검증 범위

자동 검사 27개로 주소 처리, 자료 해석, 미확인 표시, 추천 범위와 통계 계산을 확인했습니다.

추천은 공개 글에 적용한 규칙입니다. 실제 바이럴 증가와 이용자 효과는 미측정이며, 토스 사례는 캠페인 집행 경험이 아닌 공개 자료 기반 독립 분석입니다.
