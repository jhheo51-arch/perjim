# 퍼짐

**공개 콘텐츠를 읽고, 보완할 요소와 다음 콘텐츠의 구성안을 제안하는 도구입니다.**

[프로젝트 소개 PDF](docs/퍼짐-프로젝트소개.pdf) | [기획서](docs/PRD.md) | [기능 검증과 통계 기록 Excel](docs/퍼짐-기능검증과통계기록.xlsx)

현재 분석 대상은 공개 피드(RSS)를 제공하는 블로그의 제목과 본문 일부입니다. Instagram 개별 게시물, 이미지와 비공개 반응 통계는 자동으로 읽지 않습니다.

![퍼짐 서비스 화면](docs/service-preview.jpg)

## 무엇을 할 수 있나요?

`주소 입력 → 확인한 자료 읽기 → 다음 콘텐츠 검토 → 선택적으로 반응 기록`

- 읽은 글과 추천 근거를 연결해 콘텐츠 두 안과 선택 이유를 보여줍니다.
- 오늘과 이번 주 키워드에서 소재와 뉴스 근거를 확인합니다.
- 직접 입력한 게시물 반응을 계산하고, 토스 머니북 사례에서 자료와 제안의 연결을 살펴봅니다.

읽지 못한 정보는 ‘확인하지 못함’으로 표시합니다. 추천은 공개 글의 표현에 적용한 규칙이며 반응 효과를 예측하는 모델은 아닙니다.

## 어디까지 확인했나요?

자동 검사 27개로 주소 처리, 공개 자료 해석, 자료 미확인 표시, 추천 범위와 통계 계산을 확인했습니다. 실제 바이럴 증가나 이용자 효과는 아직 측정하지 않았습니다.

토스 사례는 공식 공개 자료를 읽고 만든 독립 분석입니다. 실제 캠페인 집행 경험이나 검증된 SNS 성공 공식으로 제시하지 않습니다. [사례와 추천 기준](docs/CASE-STUDY.md)

## 직접 실행하기

Node.js 22 이상에서 저장소 폴더의 터미널에 입력합니다. 별도 패키지 설치와 인증값 입력은 필요하지 않습니다.

```sh
npm start
```

브라우저에서 http://127.0.0.1:4191/ 을 엽니다. 자동 검사는 `npm test`로 실행합니다.

## 구성과 보관

HTML, CSS, JavaScript로 화면을 만들고 Node.js 서버가 허용된 공개 사이트를 조회합니다. 상세 통계와 선택 기록은 브라우저에, 키워드 수집 기록은 로컬 `runtime/`에 보관합니다. 개인 입력 기록은 GitHub에 포함하지 않습니다.
