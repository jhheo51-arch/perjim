# Trend to Trust

소비 기록을 숫자로만 보면 그때의 이유는 놓치기 쉽습니다. 지출을 돌아보게 하는 콘텐츠는 어떻게 만들 수 있을지 고민하면서 시작했습니다. 공개 자료를 살펴보고 금융 브랜드의 마케팅 업무를 맡았다면 어떤 방식으로 풀지 생각해 가계부 콘텐츠 **〈한 달의 이유〉**를 기획했고, 문장 비교 두 차례와 완성 카드 반응을 반영해 카드뉴스 6장과 원고를 고쳤습니다.

**직접 한 일:** 자료 조사, 캠페인 기획, 카피와 카드 제작, 채널별 제작안, 제휴 제안서, 응답 분석, 웹 구현. 토스의 승인이나 의뢰를 받은 프로젝트는 아닙니다.

## 30초 안내

- **문제:** 공개 트렌드를 브랜드 콘텐츠로 연결할 때, 무엇을 근거로 선택하고 반응을 어떻게 다음 수정에 반영할지 남기기 어렵습니다.
- **바로 보기:** [웹 포트폴리오](https://jhheo51-arch.github.io/trend-to-trust/)에서 기획부터 수정까지 보고, [제출 PDF](docs/submission/Trend-to-Trust-Brand-Marketing-Response-2026-10-09.pdf)에서 핵심 판단을 확인합니다.
- **확인 범위:** 공개 자료와 익명 반응 5건을 바탕으로 한 개인 프로젝트입니다. 광고 성과나 토스 고객 전체의 의견을 뜻하지 않습니다.

## 무엇을 만들었나요?

공개 경제 자료와 콘텐츠 이용 자료를 확인한 뒤, 토스가 돈을 이해하도록 돕는 브랜드로 기억되게 하는 캠페인을 제안했습니다. 가계부를 소재로 삼아 가상의 배달비 내역 4건과 72,000원의 계산 근거를 보여주고, 지출 이유는 인물이 직접 설명하게 했습니다. 인물과 거래 내역은 실제 고객 자료가 아닙니다.

Meta용 카드와 게시글 문안은 작성했습니다. YouTube와 Google용 영상은 장면별 구성안입니다. 어피티, 오늘의집, 캐릿을 비교한 뒤 어피티 공동 연재안을 썼지만 실제로 연락하거나 협업하지는 않았습니다.

## 다른 브랜드에도 적용할 수 있나요?

현재 결과물은 토스 브랜드 사례를 바탕으로 만든 캠페인 제안입니다. 브랜드 이름만 바꾸어 재사용하는 완성 서비스는 아닙니다. 다만 아래 작업 방식은 다른 브랜드에도 적용할 수 있습니다.

`공개 트렌드와 반응 확인 → 브랜드가 맡을 역할 결정 → 콘텐츠 제작 → 채널별 변형 → 반응 확인 → 다음 콘텐츠 수정`

예를 들어 오늘의집에는 주거와 생활 트렌드를 집 안의 선택과 소비 이야기로 연결할 수 있습니다. 무신사에는 패션과 세대 문화의 신호를 스타일 선택과 소비 이유를 다루는 콘텐츠로 바꿀 수 있습니다. 두 예시는 확장 방향을 설명하기 위한 것이며 실제 캠페인을 진행한 결과가 아닙니다.

## 다음 구현 단계

다음에는 브랜드 이름, 목표 고객, 브랜드가 전할 약속, 확인할 공개 자료와 후보 채널을 입력하면 첫 캠페인 기획서와 채널별 콘텐츠 초안을 만드는 범용 모델로 확장할 계획입니다. 공개 자료에서 확인한 사실, 캠페인 해석과 아직 검증하지 않은 가정을 구분하고, 최종 선택과 수정은 사람이 하도록 설계합니다. 현재 버전에는 이 자동 생성 기능이 구현되어 있지 않습니다.

## 응답을 보고 바꾼 부분

첫 문장 비교에서는 익명 응답 5건 중 4건이 숫자로 시작하는 문장을 골랐습니다. 두 번째 비교에서는 생활 맥락을 붙인 문장이 이해하기 쉽다는 선택을 3건 받았지만, 계속 볼 의향은 낮았고 실제 토스 기능으로 오해한 응답이 있었습니다. 그래서 비교 월 자료가 없는 ‘18% 증가’를 빼고, 계산 가능한 가상 내역과 인물의 말을 분리했습니다.

1차와 2차는 **각 5건의 문장 응답**입니다. 이어서 완성 카드 첫 3장에 대한 익명 응답 5건도 확인했습니다. 완성 카드에서는 계산 근거와 가상 사례를 5명 모두 구분했지만, 4명은 자동 분석 기능처럼 느꼈고 1명은 잘 모르겠다고 답했습니다. 그래서 질문형 제목을 빼고 가상 인물이 이유를 직접 적었다는 사실을 제목과 본문에 표시했습니다. 작은 표본이며 광고 성과나 전체 고객의 의견으로 해석하지 않습니다.

## 로컬 실행

웹 화면은 위 링크에서 바로 볼 수 있습니다. 공개 자료를 확인하는 보조 도구 ‘퍼짐’을 로컬에서 사용하려면 Node.js 22 이상이 필요합니다.

```sh
git clone https://github.com/jhheo51-arch/trend-to-trust.git
cd trend-to-trust
npm start
```

브라우저에서 `http://127.0.0.1:4191/`을 열면 됩니다. 보조 도구는 `/tool.html`에 있습니다. NAVER와 YouTube 연결에는 별도의 인증값이 필요하며 `.env.example`에 항목이 적혀 있습니다. 인증값은 외부 서비스를 사용할 때 제시하는 비밀값이므로 저장소에 올리지 않습니다.

```sh
npm test
```

자동 검사는 코드의 계산과 저장 동작을 확인합니다. 캠페인의 효과를 확인하는 검사는 아닙니다.
