# Trend to Trust

> 공개 트렌드와 반응에서 신호를 찾고, 그것을 토스 브랜드 캠페인 **〈한 달의 이유〉**로 발전시킨 개인 포트폴리오입니다.

토스 Brand Marketing Specialist 직무를 목표로 만들었습니다. 신호를 확인하고, 브랜드 메시지와 채널별 콘텐츠를 만들고, 작은 사용자 검증을 거쳐 다음 문장을 수정하는 과정을 한 저장소에 담았습니다.

**본인 기여:** 공개 자료 조사, 브랜드 가설·카피, 카드·원고, 매체별 제작안, 파트너 제안, 응답 분석, 웹 구현을 독립 수행했습니다. 실제 토스 광고 집행·파트너 협업·온오프라인 이벤트 경험을 이 프로젝트의 성과로 주장하지 않습니다.

## 이 프로젝트가 답하는 질문

1. **어떤 신호를 읽었나요?** 생활비 부담, 돈을 이해하려는 맥락, 정보형 콘텐츠 소비 흐름을 공개 자료에서 확인했습니다.
2. **브랜드에는 어떻게 연결했나요?** “토스는 내 돈을 쉽게 이해하도록 돕는다”는 역할을 가계부 콘텐츠 〈한 달의 이유〉로 번역했습니다.
3. **만든 뒤에는 무엇을 배웠나요?** 두 차례의 소규모 문장 비교에서 숫자의 명확성, 생활 맥락의 이해도, 실제 기능으로 오해할 위험을 따로 읽었습니다. 그 결과 첫 3장을 수정하고 완성 카드 6장에 반영했습니다.

### 실제로 확인한 것과 포트폴리오용 제안

| 구분 | 내용 |
| --- | --- |
| 실제로 확인한 것 | 공개 자료, 로컬 도구 동작, 자동 검사, 1·2차 익명 응답 각 5건의 문장 평가 |
| 포트폴리오용 제안 | 〈한 달의 이유〉 캠페인, 카드뉴스 배포, 제휴, 광고 집행 결과 |
| 아직 주장하지 않는 것 | 실제 광고 성과, 파트너 협업 성사, 전체 고객의 반응, 토스 내부 업무 경험 |

1차에서는 문장 A(“배달비가 18% 늘었어요.”)가 5명 중 4명에게 선택됐고, 다섯 명 모두 숫자의 구성이나 원인을 더 알고 싶다고 적었습니다. 2차에서는 생활 맥락을 붙인 B가 이해하기 쉬운 문장으로 3명에게 선택됐지만, 계속 볼 의향 평균은 A 4.8/5, B 3.2/5였습니다. B를 실제 기능으로 오해한 응답도 있었습니다. 비교 기준이 없는 ‘18% 증가’는 최종 카드에서 제외했습니다. 작은 표본의 문장 반응이며 캠페인 성과가 아닙니다.

## 로컬에서 실행하기

화면만 보려면 위 공개 링크를 열면 됩니다. 공개 트렌드 자료를 확인하는 도구까지 사용하려면 [Node.js](https://nodejs.org/) 22 이상이 필요합니다.

```sh
git clone https://github.com/jhheo51-arch/trend-to-trust.git
cd trend-to-trust
npm start
```

브라우저에서 `http://127.0.0.1:4191/`을 열면 포트폴리오가 표시됩니다. `http://127.0.0.1:4191/tool.html`은 보조 도구 화면입니다.

NAVER 검색어 트렌드 자동 조회는 `.env.example`을 참고해 로컬 `.env` 파일에 `NAVER_CLIENT_ID`와 `NAVER_CLIENT_SECRET`을 넣어야 합니다. YouTube 연결에는 `YOUTUBE_API_KEY`가 필요합니다. 이 값들은 외부 서비스를 사용하기 위한 비밀 출입증이므로 GitHub에 올리지 않습니다. 값이 없을 때는 화면이 연결 전 상태를 표시합니다.

```sh
npm test
```

자동 검사는 공개 자료의 확인 범위, 주소 처리, 통계 계산, 트렌드 근거 연결, 메시지 응답 저장과 문장 수정 흐름을 확인합니다. 마케팅 성과를 예측하거나 검증하는 검사는 아닙니다.
